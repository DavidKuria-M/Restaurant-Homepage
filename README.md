# Senso | Modern Italian Cuisine 🍷

A modern, high-end luxury restaurant web application built from scratch using **Webpack**, **vanilla ES6 JavaScript modules**, and dynamic **DOM manipulation**. 

![Senso Preview](https://images.unsplash.com/photo-1544025162-d76694265947?auto=format&fit=crop&w=1200&q=80)

## ✨ Features
* **Dynamic Tab-Switching:** Seamlessly switches between Home, Menu, and Contact tabs using ES6 module architecture without reloading the page.
* **Luxury Dark Aesthetic:** Styled with a deep dark brown/black palette (`#12100e`), gold accents (`#c5a059`), and Google Fonts (*Playfair Display* & *Inter*).
* **Interactive Menu:** Features categorized sections (Starters, Pasta, Main Courses, Desserts) styled in a responsive 4-column grid.
* **Interactive Location & Contact:** Includes an embedded live Google Map centered on GTC Nairobi, responsive contact info cards, and a message form.

## 🛠️ Tech Stack
* **JavaScript (ES6+):** Modular programming architecture.
* **Bundler:** Webpack 5 with Webpack Dev Server and HtmlWebpackPlugin.
* **Styling:** CSS3 (Flexbox, CSS Grid, custom gradients).
* **Build Tools:** Node.js, npm.
